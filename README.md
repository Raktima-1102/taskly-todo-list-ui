# Taskly - Minimalist To-Do List App UI

## About

Taskly is a minimalist mobile To-Do List application UI designed in Figma. The interface helps users organize their daily tasks in a simple, clean, and user-friendly way.

## Project Objective

The objective of this project is to design a clean and intuitive mobile To-Do List interface that allows users to view, add, complete, and delete tasks easily.

## Tools Used

- Figma
- Lucide Icons
- Inter Typeface

## Features

- Task list
- Add New Task section
- Task completion using checkboxes
- Today and Tomorrow status indicators
- Delete task option
- Remaining task counter
- Minimal card-based UI

## Design

The interface uses a light background, white task cards, and blue as the primary accent color. Green is used to represent completed tasks, while red is used for delete actions.

## Color Palette

| Color | Hex Code | Usage |
|---|---|---|
| Background | #F8F9FA | Main background |
| Primary Blue | #2563EB | Primary UI elements |
| Light Blue | #EFF6FF | Status elements |
| Main Text | #1F2937 | Headings and task names |
| Secondary Text | #6B7280 | Supporting text |
| Green | #22C55E | Completed tasks |
| Red | #EF4444 | Delete actions |
| White | #FFFFFF | Task cards |

## Typography

The interface uses the Inter typeface.

- Main Heading: 28 px
- Section Heading: 18 px
- Task Text: 16 px
- Status Text: 12 px
- Supporting Text: 14 px
